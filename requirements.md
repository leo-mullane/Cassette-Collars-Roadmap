# Cassette Collars prototypes – requirements

Phase 2 (greyscale). Idea numbers refer to the phase 1 opportunities list (42 ideas).

## Global
- R01 Prototype navigator replaces the live site header: pack name, Overview, prototypes 1–5, Notes switch (off by default, remembered for the session).
- R02 Previous / next pager replaces the live site footer.
- R03 Each prototype opens with a "What we're proposing / Why" panel, shown only with Notes on.
- R04 Context carries between pages with `?param=` links and a sessionStorage fallback.
- R05 The quote basket persists for the session and is reachable from every prototype (floating quote link). Ideas 20, 31.
- R06 Works at 390px and 1440px with no horizontal scroll; keyboard operable; Escape closes overlays.

## 1. Fitment finder (ideas 21, 22, 5, 38)
- R10 Page explaining what the finder does.
- R11 Model number search across all brands, partial matches, keyboard navigable.
- R12 Brand chips, then range list showing cassette body size and model count. "Another brand" route to a check request.
- R13 Result names the unit, facia (with choice where a range has several) and the collar that fits, with hole size, depth range and from-price.
- R14 Result links to the product page with size, model and facia carried; deflector can be added straight to the quote.
- R15 Help for finding the model number and asking for a check.

## 2. Quote builder (ideas 20, 3, 4, 27, 40, 41)
- R30 Three steps: items, details, sent.
- R31 Lines arrive from other prototypes or are added here; editable quantity, remove.
- R32 Opens with labelled sample lines when empty; one click clears them.
- R33 Add line: standard collar, deflector or custom collar; size, depth, colour, quantity.
- R34 Custom collar: width, length, depth, ceiling angle, photo upload.
- R35 Totals: items, volume discount, delivery, ex VAT, VAT, inc VAT; made-to-order lines flagged as priced on request.
- R36 Prompts the buyer when close to the volume discount threshold.
- R37 Details step: five required fields (name, company, email, phone as tel input, postcode); reference and notes optional; inline validation.
- R38 Confirmation with reference, summary and next steps.

## 3. Product page (ideas 23, 1, 2, 3, 19, 28, 29, 32)
- R20 One template for all five collar sizes, switched by `?size=`.
- R21 Photo gallery.
- R22 Depth input highlights the matching row and prices it; out-of-band depths become made-to-order.
- R23 Full price table ex and inc VAT; clicking a row sets the depth.
- R24 Specification including hole size, taper, material and fire rating.
- R25 Dispatch cut-off message based on the 10am rule.
- R26 "Fits these units" list generated from the fitment data.
- R27 Downloads attached per size (CAD, datasheet, fitting instructions).
- R28 What we need from you, with a how-to-measure dialog.
- R29 FAQs as an accordion.

## 4. RAL colour selector (ideas 24, 41)
- R40 Search by RAL code or name.
- R41 Filter by colour family.
- R42 Swatch grid, selectable.
- R43 Selected colour shows lead time and price effect, with a screen-colour caveat.
- R44 Go to a chosen collar size in that colour.
- R45 Apply the colour to every line in the quote.

## 5. Projects and reviews (ideas 25, 26, 8, 6, 33)
- R50 Filter by setting and product.
- R51 Project cards open a viewer with previous / next and arrow keys.
- R52 Reviews summary with placeholders for rating and count.
- R53 Review cards as bracketed placeholders; no invented quotes.
- R54 Company story with one consistent account of John Johnson and the company.
